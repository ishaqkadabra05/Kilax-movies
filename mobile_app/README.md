# Kilax Movies Flutter App

A Flutter/Dart conversion of the Kilax Movies mobile streaming interface.

## Run
```bash
flutter pub get
flutter run
```

The project includes:
- Floating pill bottom navigation
- Blue diagonal VJ ribbons
- Movie and series grids with genre chips
- Movie details and related content
- Drawer navigation
- Downloads, My List, notifications
- Contact support links
- Subscription and payment mock flow

Replace placeholder content and connect your backend before production release.
